⚡ Contoh Embed Kilat AI

Halaman ini mendemonstrasikan widget chat Kilat AI yang disematkan di website biasa.

DEMO LANGSUNG

Widget melayang

Lihat tombol ungu ⚡ di pojok kanan bawah halaman ini — klik untuk membuka chat. Itulah widget Kilat AI! Coba tanya sesuatu.

⚠️ Server Kilat AI harus sedang berjalan agar chatnya aktif. Halaman ini otomatis memakai http://localhost:8080 bila dibuka dari file, atau alamat server yang sama bila dibuka lewat /demo.

Cara 1 — Widget melayang (paling mudah)

Tambahkan satu baris ini ke HTML website Anda (sebelum </body>):

<script src="http://ALAMAT-SERVER:8080/widget.js" defer></script>

Ganti ALAMAT-SERVER dengan alamat komputer yang menjalankan Kilat AI (di komputer sendiri: localhost; di jaringan rumah: IP-nya, mis. 192.168.1.10).

Opsi tambahan: data-side="left" menempatkan tombol di kiri, data-key="kunci-anda" dipakai bila server mengaktifkan embed key.

<script src="http://192.168.1.10:8080/widget.js" data-side="left" defer></script>

Cara 2 — Iframe langsung (chat permanen di halaman)

Tempel blok ini di mana pun Anda ingin chatnya muncul:

<iframe src="http://ALAMAT-SERVER:8080/embed"
        style="width:100%;max-width:420px;height:560px;border:0;
        border-radius:14px;box-shadow:0 8px 30px rgba(0,0,0,.15)"
        title="Chat Kilat AI"></iframe>

Cara 3 — Panggil API langsung (untuk developer)

Aplikasi apa pun bisa memanggil Kilat AI lewat HTTP:

POST http://ALAMAT-SERVER:8080/api/chat
Content-Type: application/json

{
  "model": "qwen3:8b",
  "messages": [{"role": "user", "content": "Halo, apa kabar?"}],
  "tools": false
}

Balasannya berupa aliran NDJSON (satu JSON per baris): {"t":"token","v":"..."} per potongan jawaban, diakhiri {"t":"done"}.

⚠️ Hal penting sebelum dipublikasikan

  • Server harus selalu menyala selama widget dipakai — pengunjung chat langsung ke komputer/server yang menjalankan app.py
  • Website HTTPS tidak boleh memuat widget HTTP (diblokir browser). Untuk situs publik HTTPS, jalankan Kilat AI di belakang HTTPS juga (mis. reverse proxy / Cloudflare Tunnel)
  • Penggunaan rumahan (LAN): hanya perangkat di Wi-Fi yang sama yang bisa mengakses
  • Keamanan: saat dipublikasikan, jalankan dengan ARENA_EMBED_KEY=kunci-rahasia agar API tidak dipakai pihak lain — lalu tambahkan data-key="kunci-rahasia" pada tag script widget
